# ドーパミンBURST!

脳汁全開のフィールドカードバトル。ブラウザだけで遊べます（インストール不要・外部ライブラリなし）。

## 遊ぶ
- **GitHub Pages**（有効にした場合）：https://nakanaka0318.github.io/dopacard/
- **ファイルを直接開く**：`dopa-burst/dist/dopa-burst.html` をダウンロードしてブラウザで開く（1ファイル完結）

### GitHub Pages の有効化（最初の1回だけ）
1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** でこのゲームが入っているブランチ（`main` にマージ済みなら `main`）と `/ (root)` を選んで **Save**
4. 1〜2分後に上のURLで遊べるようになる

## 中身
- 12属性・111枚のカード（うち5属性25枚は「未知なる軸」：時間・位置・姿・代償・孤独）
- 6ワールド24ステージのストーリー、ランク戦、ガチャ、コインで交換できる交換所
- 先読みする敵AI（自分の手順と相手の反撃まで読んで手を選ぶ）
- 初心者サポート：攻撃予測・いまやることガイド・💡ヒント・バトルログ・ルール解説

開発者向けの説明は [`dopa-burst/README.md`](dopa-burst/README.md) を参照。
