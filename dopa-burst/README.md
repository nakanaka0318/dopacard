# ドーパミンBURST!

ブラウザで遊べるフィールドカードバトル。外部ライブラリなし、効果音とBGMもブラウザ内で合成。

## 遊び方
- `dist/dopa-burst.html` をブラウザで開くだけ（1ファイル完結。フォントだけGoogle Fontsから読み込み）
- 開発時は `index.html` を開く（`js/` と `css/` を直接読み込む）

## 構成
| ファイル | 役割 |
|---|---|
| `js/cards.js` | 17属性・136枚のカードデータと能力（うち10属性50枚は「未知なる軸」） |
| `js/engine.js` | バトルのルール（演出なしでも動く） |
| `js/ai.js` | 敵AI（盤面をコピーして実際に打ってみる先読み。自分の手順→自分のアタック→相手の反撃まで読んで評価。FEVERも「使った場合」を読んで得な時に使う） |
| `js/stages.js` | 6ワールド24ステージ・ボス能力・ランク戦の対戦相手 |
| `js/bosses.js` | ボスラッシュ：20体のボス（常時能力・必殺技・覚醒）とボス専用のEXカード40枚 |
| `js/meta.js` | セーブ・レベル・ガチャ・交換所・ミッション・ログボ |
| `js/battle-ui.js` | バトル画面の描画・操作・演出・初心者サポート（攻撃予測／ヒント／ログ／ルール解説） |
| `js/screens.js` | ホーム／ガチャ／デッキ／図鑑などの画面 |
| `js/audio.js` | WebAudioの効果音とBGMシーケンサ |
| `js/fx.js` | パーティクル・ダメージ数字・バナー |

## ツール
- `python3 tools/build.py` … `dist/` に1ファイル版を書き出す
- `node tools/sim.js 500` … AI同士を大量対戦させて例外・バランスを確認
- `node tools/stagesim.js 80` … 各ステージの勝率を確認
- `node tools/dominance.js` … 「完全上位互換」になっているカードの組がないか確認
- `node tools/rushsim.js 10` … ボスラッシュ各ボスの勝率（プレイヤー側は深さ2のAI）
- `node tools/aivs.js 300 3` … 先読みAI（深さ3）と先読みなしAIを対戦させて強さを比較
- `tools/shot.js` / `tools/scenes*.js`（`scenes5.js` は敵のFEVER、`scenes6.js` はボスラッシュ、`scenes7.js` は新しい5つの軸、`scenes8.js` はガチャ、`scenes9.js` は複数デッキ） … Playwrightで画面を撮影して確認

## 未知なる軸（追加の5属性）
| 属性 | 軸 | 仕組み |
|---|---|---|
| ⏳クロノ | 時間 | カウントが自分のターンごとに減り、0で発動 |
| 🌀ワープ | 位置 | ユニットや敵をマス移動させ、直撃コースを作る |
| 🎭ミミック | 姿 | 変身・コピー・強奪・タマゴ孵化 |
| 💔リスク | 代償 | HPを払う（HPコスト）、HPが減るほど強い |
| 🌙ソロ | 孤独 | 味方が少ない・空きマスが多いほど強い |
| 🏰フォート | 鉄壁（防御） | 守護で直撃をかばい、アーマーで受けるダメージを10減らす |
| 🌸ブルーム | 癒し（回復） | 回復が起きるたびに強くなる・攻撃に変わる |
| 🗺️ジオ | 陣地（盤面） | マスに陣（力の陣・守りの陣・落とし穴）を刻む |
| 🔮アルカナ | 呪文（スペル） | このターンに使ったスペルの数で強く・安くなる |
| 🎵リズム | 連打（コンボ） | このターンのコンボ数で化ける |

## ボスラッシュ
ホームの「BOSS RUSH」から。ストーリー1-4クリアで解放、4階層×5体。前の階層のボスを1体倒すと次の階層が開く。
ボスは **常時能力**（毎ターン）・**必殺技**（数ターンごと、画面右上にカウント表示）・**覚醒**（HPが一定以下で一度だけ）・**専用EXカード2種** を持つ。
ボス側がほぼ勝つ難しさに調整してある（深さ2のAIで操作したプレイヤーの勝率は全体で1割前後）。

## ガチャ
- 毎日1回の無料ガチャ（ノーマル×1）
- ピックアップ属性：選んだ属性のカードが同じレア度の中で5倍出やすい（未所持は1.6倍）
- チケット／ダイヤのまとめ使い（最大10パック）、演出スキップ、ガチャ履歴（直近30回）

## デッキ
- 最大8個のデッキを名前つきで保存できる（デッキ編成画面の上のタブで切り替え・名前変更・コピー・削除）
- 保存したデッキが「使用中」になる。ステージ・ボスラッシュの挑戦前にも「🃏 切替」で選び直せる
